# УЕР Вікі

Навчальна вікі з дисципліни «Управління експлуатаційною роботою» про організацію руху поїздів на залізницях України: роздільні пункти й станції, сигналізація, блокування, робота ДСП і ДНЦ, журнали та бланки, приймання й відправлення поїздів.

**Відкрити сайт:** https://dvd345.github.io/uer-wiki/

Автор: Кунець Давід, студент групи 103-ОПУТ-Д24, Український державний університет залізничного транспорту (УкрДУЗТ).

## Структура

- `*.html` — сторінки вікі
- `assets/` — стилі, скрипти, зображення, відео
- `_джерело/src` — тексти сторінок
- `_джерело/build.py` — збирання сторінок і пошукового індексу
